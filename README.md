# AI Chatbot 

## Description
This is a full-stack AI chatbot built using Node.js and JavaScript.

## Features
- Real-time chat
- AI-generated responses
- Markdown formatted output
- Typing indicator
- Clean UI

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- AI API: Groq API

## How to Run
1. Clone the repo
2. Install dependencies: npm install
3. Add .env file with API_KEY
4. Run server: node server.js
